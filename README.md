# NextGen_Week_1_Data_Analytics
# Week 1 – Introduction to Data Analytics

## Internship
**Data Analytics Internship – Next Gen Software Hub Pvt. Ltd.**

## Overview

Week 1 focused on the fundamentals of Data Analytics, spreadsheet-based data handling, data cleaning, and basic analysis using Excel/Google Sheets.

## Topics Covered

- Basics of Data Analytics
- Excel / Google Sheets
- Data Cleaning Techniques
- Data Entry Analysis
- Basic data interpretation

## Dataset

The dataset contains sales and data-entry information with the following fields:

- Date
- Customer ID
- Product
- Region
- Quantity
- Unit Price
- Revenue

**Note:** The dataset used for this task is a synthetic/practice dataset because an official company dataset was not provided.

## Data Cleaning

The following data preparation activities were performed:

- Identified missing values
- Removed duplicate records
- Checked data consistency
- Corrected data-entry issues
- Prepared the cleaned dataset for analysis

## Analysis

Basic analysis was performed using spreadsheet tools to understand:

- Product-wise sales
- Region-wise sales
- Quantity information
- Revenue generated
- Overall data-entry patterns

## Tools Used

- Microsoft Excel
- Google Sheets
- CSV
